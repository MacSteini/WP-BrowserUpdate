A clear browser update notice for WordPress visitors.

WP BrowserUpdate helps a WordPress site warn people when their browser is too old for the experience you want to support.

You decide where the line is. The plugin handles the notice, the wording and the visitor-facing files from your own site.

Your browser is out of date.

Please update your browser to use this website safely and comfortably.

Update browser

Start with the visitor, not the browser list.

The plugin is meant for a simple situation: someone opens your site with an outdated browser, and you want to give them a useful next step without breaking the page for everyone else.

Detect the gap

Set the browser versions you still support, including exact dotted versions when you need that level of control.

Explain the issue

Show a short notice with your text and your browser download targets, instead of leaving visitors to guess.

Stay in WordPress

Configure the notice from a normal settings screen and test it before showing it to real traffic.

Built to avoid avoidable frontend surprises.

The browser notice runtime is bundled with the plugin, so the public page does not need to fetch the notice scripts or styles from browser-update.org.

  • Visitor-facing runtime files load from the WordPress site.
  • This is friendlier to strict Content Security Policies and tracker blockers.
  • browser-update.org remains the credited upstream project for the notification runtime.

Control the notice without turning it into a project.

Most sites can keep the defaults. When you need more precision, the settings stay focused on decisions a site owner can understand.

Browser thresholds

Use defaults, major versions, negative offsets or exact dotted versions such as 137.0.3912.63.

Separate targets

Handle modern Edge, legacy Internet Explorer and additional browser targets separately.

Reminder rhythm

Choose how soon a dismissed notice may reappear for the same visitor.

Text and appearance

Adjust wording, links and site-specific CSS without printing raw style blocks into the page.

Native admin screen

Use one focused WordPress settings page instead of a separate dashboard.

Safe testing

Force the notice while setting up, then disable test mode before real visitors see the site.

Install from WordPress.org. Review the source on GitHub.

For normal WordPress installation and updates, use the plugin directory. For source review and issue tracking, use the GitHub repository.
