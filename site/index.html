WP BrowserUpdate shows clear browser notices.

WP BrowserUpdate helps WordPress sites warn people when a browser is too old for the intended site experience.

Site owners define the support threshold. The plugin handles the notice, the wording and the visitor-facing files from the WordPress site.

Your browser is out of date.

Please update your browser to use this website safely and comfortably.

Update browser

Start with the visitor, not the browser list.

The plugin covers a simple situation: someone opens a site with an outdated browser, and the site can offer a useful next step without disturbing everyone else.

Check browser support

Supported browser versions can be defined with defaults, major versions or exact dotted versions when that level of control is needed.

Explain the issue

A short notice can use site-specific text and browser download targets, so visitors are not left to guess.

Stay in WordPress

The notice is configured from a normal settings screen and can be tested before it appears for real traffic.

Built to avoid avoidable frontend surprises.

The browser notice runtime is bundled with the plugin, so the public page does not need to fetch the notice scripts or styles from browser-update.org.

  • Visitor-facing runtime files load from the WordPress site.
  • This is friendlier to strict Content Security Policies and tracker blockers.
  • browser-update.org remains the credited upstream project for the notification runtime.

Control the notice without turning it into a project.

Most sites can keep the defaults. When more precision is needed, the settings stay focused on decisions a site owner can understand.

Browser thresholds

Defaults, major versions, negative offsets and exact dotted versions such as 137.0.3912.63 are supported.

Separate targets

Modern Edge, legacy Internet Explorer and additional browser targets can be handled separately.

Reminder rhythm

The reappearance delay controls when a dismissed notice may return for the same visitor.

Text and appearance

Wording, links and site-specific CSS can be adjusted without printing raw style blocks into the page.

Native admin screen

Configuration stays in one focused WordPress settings page instead of a separate dashboard.

Safe testing

Test mode can force the notice during setup and is disabled again before real visitors see the site.

Install from WordPress.org. Review the source on GitHub.

For normal WordPress installation and updates, use the plugin directory. For source review and issue tracking, use the GitHub repository.
